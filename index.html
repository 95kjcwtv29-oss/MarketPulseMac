MarketPulse
Installazione locale per Mac mini M1
Perché questa pagina non mostrava i dati?
Questa è una preview statica online: il browser può bloccare le richieste dirette alle API finanziarie (CORS). La versione corretta interroga le fonti da un server locale sul tuo Mac. Questa pagina quindi serve da avvio, non da dashboard live.

Avvia l'installazione in un solo passaggio

Apri Terminale sul Mac (⌘ Spazio → digita “Terminale”) e incolla il comando qui sotto. Scarica il progetto direttamente dal repository GitHub, installa MarketPulse in ~/Applications e apre la dashboard nel browser. Non scarichi allegati da ChatGPT.

Cosa succede dopo

01 / INSTALLA

Il comando recupera il codice da GitHub e crea l'app sul Mac.

02 / APRI

Si apre la dashboard locale su http://127.0.0.1:8765.

03 / AGGIORNA

Il backend locale interroga prezzi, notizie, community e Polymarket evitando i limiti CORS del browser.

Richiede Python 3. Il server ascolta solo sul computer locale. Se l'installazione mostra un errore, copia qui il testo del messaggio e correggerò il problema.
